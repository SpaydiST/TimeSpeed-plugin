# TimeSpeed Plugin

Версия: 1.5.5 · API Paper 26.2 · `load: POSTWORLD` · Java 25

## Полное описание работы

### 1. Загрузка (`onEnable`)

1. `Config.reload(plugin)` — читает `config.yml`, заполняет статические поля конфига (в т.ч. один раз разбирает `cursed-ring-item` в набор `Material`).
2. `Lang.load(plugin)` — выгружает дефолтные `lang/*.yml` из jar в папку плагина и загружает все языки.
3. `new SleepHandler(plugin)` + `.start()` — запускает цикличный таймер (первый тик через 20, дальше каждый тик) для перемотки сна/грозы.
4. Регистрация команд и tab-комплетеров: `/afk`, `/timespeed`.
5. Регистрация слушателей событий:
    - `TimeSpeedPlugin` — `PlayerJoinEvent` / `PlayerQuitEvent` (инициализация и очистка данных AFK);
   - `ActivityTracker` — движение, чат (2 варианта события), команды, клик по блоку;
   - `SleepHandler` — `TimeSkipEvent`.

### 2. Системы

- **AFK** (`ActivityTracker` / `AfkCommand`): авто-AFK через 5 минут бездействия (движение/чат/команда/клик сбрасывают таймер) + ручной тумблер `/afk`. Состояние вычисляется на лету через `isAfk()`.
- **Сон** (`SleepHandler`):
  - Перехватывает ванильный `TimeSkipEvent(NIGHT_SKIP)` в обычном мире — отменяет мгновенный скачок;
  - каждый тик одним проходом по игрокам считает валидных и спящих (без AFK, спектаторов и игроков с «проклятым кольцом») и плавно перематывает время со скоростью до `max-sleep-speed` (по умолчанию 100x), с lerp-сглаживанием;
  - пока в мире активна перемотка `/timespeed`, обработка сна ставится на паузу (спящие остаются в кроватях, после команды система плавно продолжается или срабатывает «утро»), чтобы два таймера не конфликтовали;
  - «проклятое кольцо»: точное сравнение по `Material` (набор разбирается один раз при загрузке, ноль аллокаций в тике) + опциональная PDC-метка `timespeed:cursed_ring` для кастомных предметов;
  - работает даже при выключенном натуральном ходе времени (`advance_time=false`, бывший `doDaylightCycle`) — перемотка двигает время явно через `World.setTime()`; в логе при старте будет одно информационное сообщение;
  - прогресс-бар «🌙 ▓▓▓░░░ N сек.» только спящим;
  - в конце — сообщение «утро», сброс грозы, пробуждение, сброс статистики фантомов (одним проходом по игрокам);
  - `getWorldSpeed(world)` — публичный API текущей скорости для других плагинов (HUD часов).
- **`/timespeed <sunrise|day|noon|sunset|night|midnight|0–24000>`** — плавная перемотка вперёд вручную, per-world таймер, прогресс-бар «⏩» только для игроков с `timespeed.time`; новая команда отменяет текущую перемотку.
- **Локализация** (`Lang`): 34 языка в `lang/*.yml` (дефолты выгружаются из jar при первом запуске, редактируются прямо в папке плагина) + карта всех ~120 локлей Minecraft; сообщения подбираются по `player.locale()`.

### 3. Выключение (`onDisable`)

`sleepHandler.stop()` → `Bukkit.getScheduler().cancelTasks(plugin)` отменяет все таймеры плагина (и сон, и перемотку `/timespeed`). Все данные в памяти теряются.

### 4. Права

- `timespeed.afk` — по умолчанию у всех;
- `timespeed.time` — только у операторов.

### 5. Конфиг (`config.yml`)

| Ключ | По умолчанию | Описание |
|------|-------------|----------|
| `enable-sleep-system` | `true` | Включить систему плавного сна |
| `max-sleep-speed` | `100.0` | Максимальная скорость перемотки сна |
| `speed-lerp-factor` | `0.15` | Плавность разгона/торможения скорости |
| `fast-time-speed` | `100.0` | Скорость перемотки `/timespeed` |
| `enable-thunder-skip` | `true` | Спать можно и во время грозы |
| `cursed-ring-item` | `""` | Предмет(ы), игнорирующие сон (имена Material через запятую) |
| `cursed-ring-pdc` | `false` | Проверять PDC-метку `timespeed:cursed_ring` на предметах |
| `reset-phantoms-for-all` | `true` | Сбрасывать фантомов всем игрокам |
| `enable-afk-system` | `true` | Включить авто-AFK |
| `afk-timeout-minutes` | `5` | Таймаут бездействия для авто-AFK |
| `enable-manual-afk` | `true` | Включить команду `/afk` |
